# NiyamTrace-X - Frontiers submission-ready package

Target: **Frontiers in Artificial Intelligence**, **Logic and Reasoning in AI**, **Original Research**.

Frontiers recommends its LaTeX template but states that it is not mandatory. This package follows the current submission structure and file requirements while compiling on standard Overleaf.

## Portal upload
1. Upload the compiled manuscript PDF.
2. Upload the LaTeX source files and `references.bib`.
3. Upload `submission_figures/Figure_1.jpg` through `Figure_6.jpg` individually as figure files.
4. Paste `SCOPE_STATEMENT_200_WORD_MAX.txt` into the scope statement field.
5. Use `SUBMISSION_PORTAL_METADATA.md` when entering journal/section/article-type/author information.

Final author-side checks remain for CRediT contributions, APC-support wording, and all-author approval.
