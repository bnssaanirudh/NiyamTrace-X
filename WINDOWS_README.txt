NiyamTrace-X Windows-safe research archive
==============================================

This archive is a Windows-compatible rebuild of the complete AMD-to-current research package.
Windows-forbidden filename characters were replaced and overlong paths shortened.
No file payloads were intentionally removed. See WINDOWS_PATH_RENAME_MAP.csv for every changed path.
Extract close to the drive root (for example C:\NTX) for maximum Windows compatibility.
