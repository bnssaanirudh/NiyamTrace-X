NiyamTrace

Assure every action.
In every language.

NiyamTrace is a local-first platform that ensures tool-using AI agents perform the exact same safe database actions whether you ask them in English, Hinglish, Telugu, or Romanized Telugu. It converts fuzzy LLM requests into strict, verifiable contracts before any real-world change occurs.

How Gemini Thinks

The Five-Stage Assurance Pipeline

01

Multilingual Intake

The user's raw text is parsed. Language, script, and code-mixed spans are identified and normalized so the agent isn't confused by slang or transliteration.

02

Intent Contract

The AI extracts a strict JSON contract (Action, Target, Time Scope). It refuses to guess missing dates—ambiguity forces a clarification.

03

Evidence & Policy

Retrieval-Augmented Generation (RAG) fetches company policies. If the policy contradicts the requested action, the system halts immediately.

04

Gate Simulation

Before any execution, a "shadow simulator" predicts exactly which database rows the agent's tool will mutate. If it touches unauthorized rows, the Gate blocks it.

05

Execution & Traces

Only if all 5 safety checks pass is the tool executed. Every decision, latency metric, and database change is logged to a Lakehouse for review.
