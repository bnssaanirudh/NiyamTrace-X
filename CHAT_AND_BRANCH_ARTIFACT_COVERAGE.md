# Main-chat / branch-chat artifact coverage

This archive merges all NiyamTrace-X research artifacts that were recoverable from the saved file Library, current conversation-mounted artifacts, the earlier complete research-history package, and the public repository state verified during packaging.

It includes artifacts produced across the main research thread and follow-up/branch work: AMD MI300X experiment logs, frozen runtime evidence, stages 01–15, Wave-3 notebooks/results, recovery runs, local T4/open-weight attempts, three-family external-validation attempts, current manuscripts, figures, sources, audits, and submission packages.

Raw ChatGPT message-history export is not available as a file-system artifact here, so this ZIP does not claim to contain a verbatim transcript of every chat message. It does contain the recoverable files/code/results created from those chats, plus provenance maps and hashes.
